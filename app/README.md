# App for `bebsapati`

## how to run

#### Install

[bun](https://bun.sh/docs/installation])

[Expo Go](https://play.google.com/store/apps/details?id=host.exp.exponent&hl=en)

#### clone this repo. then inside `bebsapati-app` run the following:

`bun install`

`bun start`

a qr code will appear in the terminal. Scan the qr code using `Expo Go` app.

#### to release the app:

`eas build --profile production --platform android`
